## Главное

Суды Казахстана перешли со старого **office.sud.kz** на новый **Единый портал судебных органов — portal-sot.kz**
(по данным release notes проекта SudProductKz на GitHub — с 21 сентября; официальное объявление стоит найти отдельно).
Поэтому office.sud.kz и не открывается.

## API графика заседаний (portal-sot.kz)

Справочники (без входа):

```
GET https://portal-sot.kz/api/public/dictionary/district/search            — области
GET https://portal-sot.kz/api/public/dictionary/court/search?DISTRICT_ID=2 — суды области (поле CODE)
GET https://portal-sot.kz/api/public/dictionary/case_type/search           — CIVIL, CRIMINAL, ADMINISTRATIVE, APPK
GET https://portal-sot.kz/api/public/dictionary/instance_type/search       — FIRSTINSTANCE, APPEAL, CASSATION, SUPERVISION
```

График:

```
GET https://portal-sot.kz/api/public/schedule/find/{courtCode}/{instance}/{caseType}/{YYYY-MM-DD}
пример: /api/public/schedule/find/197142/FIRSTINSTANCE/CIVIL/2026-11-11
```

Ответ: `{"status":0,"data":[{ "uid", "time", "judge", "applicants":[{"name"}], "defendants":[{"name"}],
"sides", "hallNumber", "caseNumber" }]}`.
Результаты проверки на живых данных — в [FINDINGS.md](FINDINGS.md).

## Ограничения графика

- **Не больше 50 дел на один запрос** (суд + день), сам сайт показывает столько же. В крупных судах это только
  часть заседаний, поэтому «не найдено» не значит «заседания нет». Парсер пишет об этом предупреждение.
- Дел «ОСИ против жильца» в графике почти нет (см. FINDINGS.md): по закону такие долги можно взыскивать
  через исполнительную надпись нотариуса, без суда.
- Только **назначенные заседания**, а не все дела. Приказное производство (частый путь взыскания с должников ОСИ)
  может пройти без заседания и в график не попасть.
- В графике **ФИО, без ИИН** → совпадение по ФИО помечаем «нужна проверка».
- Нет категории и статуса дела; статус косвенно — «назначено заседание на дату».
- Один запрос = один суд × одна дата → нагрузку держим низкой (пауза, только гражданские суды нужного города).

## Банк судебных актов (portal-sot.kz, после входа по ЭЦП)

- **Фильтры:** тип производства и учётный год (обязательны), инстанция, ключевое слово; в расширенном поиске —
  категория дела, область, суд, ИИН/БИН стороны, истец, ответчик, адвокат, результат рассмотрения.
- **В списке результатов:** номер дела, стороны, суд, результат, категория; по 10 дел на странице.
  Без фильтров показывается «Найдено дел: 10000», похоже, это предел показа, а не настоящее число.
- **Особенность:** в списке категорий есть дубли. Со строчными буквами поиск возвращает «не найдено»,
  рабочая категория записана заглавными («СПОРЫ, ВОЗНИКАЮЩИЕ ИЗ ЖИЛИЩНЫХ ПРАВООТНОШЕНИЙ»).
- **Карточка дела:** суд, категория, результат и список документов (дата, тип, файл `.docx`).
  Кто истец и кто ответчик, в карточке не указано, это видно только в тексте решения.
- Пример: категория жилищных споров + слово «объединение собственников имущества», 2025 год, первая инстанция:
  **224 дела**. Результаты анализа — в [PRACTICE.md](PRACTICE.md).
